# 天氣查詢

使用 `scripts/get_weather.py` 查詢天氣，資料來源為 Open-Meteo（免 API key）。

## 步驟

1. **判斷城市與天數**
   - 從使用者的訊息或參數 `$ARGUMENTS` 取出城市名稱；第二個參數若是數字，視為預報天數。
   - **一律將城市名稱轉成英文再查詢**（例如「台北」→ `Taipei`、「高雄」→ `Kaohsiung`、「東京」→ `Tokyo`），因為中文地名在地理編碼 API 中常查不到或對應到錯誤地點。
   - 沒有指定城市時，先詢問使用者要查哪個城市，不要自行猜測。
   - 沒有指定天數時使用預設值 3；「這週」、「一週」用 7。

2. **執行腳本**（腳本與本檔位於同一個 skill 目錄下）

   ```bash
   python3 <本 skill 目錄>/scripts/get_weather.py "<英文城市名>" --days <天數>
   ```

3. **處理錯誤**
   - 輸出「找不到城市」時：改用其他拼法再試一次（例如 `Taipei City`、`Tainan`）。仍失敗再請使用者確認地名。
   - 檢查輸出的「地點」是否符合使用者的意思（國家是否正確），不符合時改用更明確的英文名稱重查。
   - 輸出「無法取得天氣資料」時：告知使用者網路或 API 暫時無法連線，不要編造天氣資料。

4. **整理回覆**
   - 用使用者的語言回覆，先講目前天氣，再列出每日預報。
   - 最後加一句實用建議，例如：降雨機率 ≥ 50% 建議帶傘；高溫 ≥ 32°C 提醒防曬補水；低溫 ≤ 12°C 提醒保暖。
   - 只根據腳本輸出回答，不要自行補充腳本沒有提供的數據。

## 範例

使用者：`/weather 台北 5`

執行：`python3 .../scripts/get_weather.py "Taipei" --days 5`

回覆：
> 台北目前多雲，氣溫 24°C（體感 26°C），濕度 78%。
> 未來 5 天：……
> 週四降雨機率 70%，出門記得帶傘。
